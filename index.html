Rekod hari ini

Tekan sebarang rekod untuk membatalkannya jika tersilap. Pengawas dan guru hanya boleh membatalkan rekod sendiri pada hari yang sama.

Urus pelajar

Tambah seorang pelajar

Guna borang ini untuk pelajar baharu atau pertukaran kelas pertengahan tahun. ID dijana sistem.

Import dari CSV

Lajur: Nama, Tingkatan, Kelas. Jika ada satu baris bermasalah, tiada apa yang disimpan sehingga fail dibetulkan.

Dari Excel: File > Save As > CSV UTF-8. Pelajar yang tiada dalam fail akan ditanda tidak aktif (tidak dipadam).

Awal tahun (kelas disusun semula): eksport senarai, tukar Tingkatan dan Kelas dalam Excel, kemudian import semula. Lajur ID_Murid mengekalkan ID dan rekod lama. Pelajar baharu: biarkan ID kosong.

Senarai pelajar

Tetapan

Tambah pengguna

ID dijana ikut peranan (PGW, GRU, ADM). PIN sementara dipaparkan sekali sahaja dan wajib ditukar semasa login pertama.

Senarai pengguna

Ketik pengguna untuk reset PIN atau tukar status. Pengguna tidak aktif terus dilog keluar.

Waktu bertugas pengawas

Pengawas hanya boleh login dalam tempoh ini. Sesi pengawas tamat pada waktu tamat.

Had lewat

Murid yang tiba selepas masa ini dikira lewat. Tepat pada masa ini tidak lewat.

Had tindakan sebulan

Murid yang lewat sebanyak ini (atau lebih) dalam sebulan disenaraikan dalam laporan "Capai had tindakan".

Sebab lewat

Pilihan yang dipaparkan semasa merekod. Mengubah senarai ini tidak mengubah rekod lama.
